# C언어의 문자와 문자열

C언어에서 **문자(char)**와 **문자열(string)**은 컴퓨터가 텍스트 데이터를 다루는 가장 기본적인 방식이다. 문자는 단일 글자를, 문자열은 여러 문자의 연속을 의미하며, 이들은 모두 메모리와 자료형의 관점에서 특별한 구조를 가진다.

C언어의 문자열은 별도의 자료형이 아닌, **char형 배열**로 표현된다. 각 문자는 1바이트(8비트) 크기의 `char` 자료형에 저장되며, 문자열의 끝은 반드시 **널 문자(`'\0'`)**로 표시된다. 이 종료 문자가 없다면, C언어는 어디까지가 문자열인지 알 수 없다.

문자와 문자열을 다루기 위해 C언어는 `<string.h>` 헤더 파일을 통해 다양한 표준 라이브러리 함수를 제공한다. 이 함수들은 문자열의 길이 측정, 복사, 비교, 연결 등 다양한 작업을 효율적으로 수행할 수 있게 해준다.

이 문서에서는 C언어에서 문자를 저장하는 방식, 문자열의 구조와 선언 방법, 그리고 문자열 관련 표준 함수들의 기본적인 사용법을 체계적으로 설명한다. 이러한 기초 개념을 정확히 이해하는 것은 텍스트 데이터 처리와 더불어, 이후 고급 프로그래밍 주제를 학습하는 데 필수적인 기반이 된다.
